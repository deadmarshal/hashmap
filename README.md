# hashmap

A simple [Hashmap](https://en.wikipedia.org/wiki/Hash_table) implementation in [Modula-3](https://github.com/modula3/cm3) using Sequences.

# How to build
From the root folder of this repo invoke:

```console
cm3
cm3 -ship
```

Now the library is installed in your cm3/pkg folder (e.g. ~/cm3/pkg)
